# Research and implementation plan

## Device facts verified over ADB

The TV reports model `MiTV-AXFR0`, codename `rango`, Android 11 (API 30), a 1280 × 720 interface at density 213, and `MemTotal: 1012412 kB` (about 1 GiB). The `/data` filesystem is 4.0 GiB, with about 2.0 GiB free at inspection. These are readings from this device, and are more useful than retail specifications for a different Redmi series. Netflix (`com.netflix.ninja`), YouTube (`com.google.android.youtube.tv`), and Xiaomi TV+ (`com.mitv.tvhome.mitvplus`) are installed. The original HOME is `com.google.android.tvlauncher/com.google.android.tvlauncher.MainActivity`.

The 1 GiB RAM figure is a reason to keep the launcher small. It does not imply that unused RAM must be emptied: Android keeps apps cached for faster return and reclaims memory when needed ([Android memory overview](https://developer.android.com/topic/performance/memory-overview)).

## What existing launchers show

[Free My TV](https://github.com/simbasjungles/free-my-tv) uses a lean Java/Canvas implementation and shows that a compact TV launcher is feasible. Its published memory improvement is a measurement from one TCL set and does not predict performance on this Redmi. Its Xiaomi package disable list includes Xiaomi TV+, which conflicts with this user's requirement, so this project does not copy that approach. [FLauncher](https://gitlab.com/flauncher/flauncher) uses Flutter. Still Home uses native Android Views and Java, with no runtime library dependency, to reduce startup and memory overhead on this 1 GiB TV.

## Design and implementation

1. **Home:** an exported `MAIN + HOME + DEFAULT` activity, plus a separate `LEANBACK_LAUNCHER` entry and TV banner. The Home button is routed by Android; an ordinary activity cannot intercept it ([Android Home key](https://developer.android.com/reference/android/view/KeyEvent), [TV app setup](https://developer.android.com/training/tv/get-started/create)).
2. **Apps:** query `LEANBACK_LAUNCHER` first and `LAUNCHER` second, with manifest `<queries>` declarations required by Android 11 package visibility ([package visibility](https://developer.android.com/training/package-visibility/declaring)). Explicit known packages cover Netflix, YouTube and [Xiaomi TV+](https://play.google.com/store/apps/details?id=com.mitv.tvhome.mitvplus). Launch the exported component Android reports; do not hard-code app activities.
3. **Visuals:** Horizon shelf is the chosen runtime layout. Wallpapers are small bundled JPEGs or a personal image sent from the Mac; custom photos decode on a worker thread in RGB 565. A static tinted panel gives a glass-like feel without per-frame blur. Only focus changes animate, for 130 ms. This TV resolves Android document intents to a nonfunctional framework stub, so the personal-image workflow uses `scripts/send_wallpaper.py` and the installed debug app's `run-as` access. The transfer validates the image on the Mac, keeps at most 12 imports, and offers removal by holding OK on a photo in Settings.
4. **Screensaver:** register a `DreamService`, show the chosen wallpaper dimmed, and shift the clock slightly once per minute ([DreamService](https://developer.android.com/reference/android/service/dreams/DreamService)). This TV does not resolve `android.settings.DREAM_SETTINGS`, so `scripts/configure_screensaver.py` checks that the service is installed, saves the original secure setting in a TV-bound backup, selects Still Home's service, verifies it, and can restore the original value. Android still controls when it runs.
5. **Maintenance:** show actual storage/memory state and open system App info/storage tools. A normal app cannot clear other apps' caches: `CLEAR_APP_CACHE` is privileged ([permission reference](https://developer.android.com/reference/android/Manifest.permission)). Android also discourages third-party task killers as performance tools ([Android 14 process behavior](https://developer.android.com/about/versions/14/behavior-changes-all)).
6. **Deployment:** install via authenticated ADB over this LAN and test as an ordinary app. This firmware's Google TV HOME filter has priority 2 while a nonprivileged third-party app's positive priority is capped to 0 ([intent-filter reference](https://developer.android.com/guide/topics/manifest/intent-filter-element)). Setting the HOME role alone reports success but the Home key still opens Google TV. The TV blocks disabling its individual Home activity, so setup additionally uses `pm disable-user --user 0 com.google.android.tvlauncher`. This leaves Xiaomi TV+ and the rest of Android installed. Restore by enabling that package first, then setting the original HOME component. Both directions were verified on this TV. Xiaomi documents how to enable ADB debug on Mi TV ([Xiaomi support](https://www.mi.com/uk/support/article/KA-06513/)); Android documents ADB's authorization and connection model ([ADB guide](https://developer.android.com/tools/adb)).

## Device verification

The debug APK was built and installed on this TV. ADB key events exercised Home focus and D-pad navigation, the scrolling All apps grid with 21 launchable apps, hold-OK favorite changes, and return from Netflix, YouTube, and Xiaomi TV+ via the Home key. Built-in wallpaper changes, a Mac photo transfer and removal, screensaver preview and secure-setting selection, and the maintenance screen were checked on the device. The original Google TV Home setup was restored once and then Still Home was selected again. The TV is now left on Still Home. Two `dumpsys meminfo` snapshots with Home open showed 52,950–66,537 kB total PSS. One rapid 12-key ADB navigation run after app loading showed a 14 ms median frame time and one frame-deadline miss across 30 frames. ADB injection reported high input latency, so this is a local diagnostic rather than a remote-control performance guarantee. Physical-remote key mapping and the firmware's natural screensaver idle trigger have not been independently timed.

## Limits

Still Home changes only the HOME experience. It cannot remove ads inside other apps, guarantee playback performance, force-stop arbitrary apps, or silently clear system caches. Xiaomi firmware might retain special keys that open PatchWall. The stock Google TV launcher package stays installed but is disabled for user 0 while Still Home is Home; this also removes Google TV launcher features until rollback. Xiaomi TV+ remains installed and enabled. Personal ADB installs remain permitted under Google's 2026 developer verification rules ([official FAQ](https://developer.android.com/developer-verification/guides/faq)).
